# Phase 18.2.11.2.4 — Edit Selected completion

The Asset Manager must expose **Edit Selected** beside Add Asset. Asset ID and Master Canonical Reference are read-only in normal editing. Name, category, status, tags and description remain editable. Category changes require an explicit warning because they may affect future reference-template/readiness rules. Canonical changes belong in Canonical Profiles, and the edit dialog exposes an **Open Canonical Profile** action. MASTER replacement is intentionally deferred to a controlled canonical revision workflow.
