# VSCS Roadmap Documentation

## Authoritative forward roadmap

For all forward development planning, use:

**`VSCS_ARCHITECTURE_VNEXT_ROADMAP.md`**

This is the adopted post-rationalisation roadmap covering the controlled development path through Phase 26 and product completion.

## Supporting roadmap documents

- `MILESTONE_TRACKER.md` — milestone tracking and status evidence.
- `RELEASE_PLAN.md` — release planning and release gates.
- `TEST_PLAN.md` — testing strategy.
- `CHANGELOG.md` — roadmap/project change history.
- `DECISIONS.md` — architectural decisions.
- `VSCS_v1_Roadmap.md` — earlier roadmap retained for historical traceability.

Where the older `VSCS_v1_Roadmap.md` conflicts with the adopted Architecture vNext roadmap, **`VSCS_ARCHITECTURE_VNEXT_ROADMAP.md` governs forward planning** unless a later explicit architectural decision supersedes it.

Detailed implementation phase documents may refine subphase numbering and add corrective/validation phases while preserving the major dependency order and milestone outcomes defined by Architecture vNext.
