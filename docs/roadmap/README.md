For architectural sequencing, major dependencies and long-term development principles, use:

**`VSCS_ARCHITECTURE_VNEXT_ROADMAP.md`**

This is the adopted post-rationalisation **architecture** roadmap covering the controlled development path through Phase 26 and product completion. The operational MASTER backlog sets delivery order without overriding approved architecture constraints.
