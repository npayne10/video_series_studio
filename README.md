# Video Series Studio

Video Series Studio is the host application for the Video Series Creation System (VSCS).

**Development starting point:** [VSCS MASTER Delivery Backlog and Decision Register](docs/roadmap/VSCS_MASTER_DELIVERY_BACKLOG.md) — current priority, next task, accepted decisions, completion evidence and remaining delivery work.

This repository will contain the core framework, project management, asset management, story analysis, production planning, rendering integration, and post-production modules.
